Chapters 1–6

Origins & the Green Project

Java began as Oak inside Sun’s Green Project for embedded consumer devices — not as a web language. The Internet pivot came later.

In the late 1980s and early 1990s, code written for one processor or OS often had to be rewritten for another. Sun’s engineers expected networked devices and consumer electronics to need portable, secure software. The Computer History Museum records April 8, 1991 as the day Sun’s team moved into secret work on Oak. James Gosling designed the language; Patrick Naughton helped initiate the work; Mike Sheridan helped lead product direction.

JVM, Bytecode, and WORA

Java is a platform, not only a language. Source compiles to bytecode in .class files; a JVM loads, verifies, and executes that bytecode — the technical basis for Write Once, Run Anywhere. James Gosling designed the virtual machine that evolved into the JVM in 1992.

HotJava, JDK 1.0, and the web (1995–1996)+

Oak was renamed Java because the Oak trademark was unavailable. Sun introduced Java and the HotJava browser in 1995; Netscape’s commitment to Java in Navigator gave early visibility. JDK 1.0 shipped in January 1996 with the JVM, AWT, networking, threads, garbage collection, and sandbox security.

Applets: rise, decline, and removal+

Applets made the web interactive in the mid-1990s, but browser plugins became a security burden. The deployment stack was deprecated in Java SE 9–10 and dropped from Java SE 11 onward. JDK 26 removed the Applet API entirely (JEP 504).

JCP, Java EE → Jakarta EE, and Spring+

The Java Community Process (1998) standardizes specs through JSRs, reference implementations, and TCKs. Enterprise Java became J2EE, then Java EE, then Jakarta EE under Eclipse — Jakarta EE 9 moved APIs from javax.* to jakarta.*. Spring Framework 1.0 shipped in 2004; Spring Boot 1.0 in 2014 reshaped cloud-native Java development.

OpenJDK and modern release cadence+

Sun open-sourced major JDK parts through OpenJDK in 2006. Since Java 10/11, feature releases ship every six months; LTS lines (8, 11, 17, 21, 25) receive extended support.
